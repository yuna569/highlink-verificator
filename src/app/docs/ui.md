컴포넌트
1. 인플루언서 정보 카드
    1. 정보
        1. 이름
        2. 이메일
        3. 활동 중인 소셜 채널(인스타그램, 틱톡, 유튜브 중 복수 선택)
        4. id
            1. 인스타그램 링크
            2. 틱톡 링크
            3. 유튜브 링크
    2. 팔로워 수 입력
        1. 인스타그램 팔로워 수
        2. 틱톡 팔로워 수
        3. 유튜브 팔로워 수
    3. 승인 버튼
        1. 1.1.2에서 입력한 소셜 채널들 모두에 대해 팔로워 수를 입력하면 활성화
        2. 클릭 시 db(supabase)에 팔로워 수 반영 + 승인(is_approved = TRUE)
2. 승인 완료 인플루언서 정보 카드
    1. 정보
        1. 이름
        2. 이메일
    2. 활동 중인 소셜 채널에 따른 팔로워 수
        1. 수정 가능
3. 사이드 바: 페이지 전환
